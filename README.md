# Market IQ Admin Prototype

This repository hosts the standalone, interactive Market IQ Admin prototype for System Admin.

**Prototype:** https://chavens77.github.io/Market-IQ-Admin-Prototype/

## Prototype boundaries

- This is a static demonstration with sample data only.
- It does not connect to dealer, customer, AI, or production services.
- Changes remain in the current browser session and are not published to a live environment.
- This Pages site and deployment workflow are independent of all other prototype repositories.

Only the compiled static site is published here. Internal source packages, environment files, and the other Market IQ prototype are intentionally excluded.
